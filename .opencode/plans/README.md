# Plans

Persistent, committed implementation plans for any project.

## Quickstart

1. Copy template from `templates/plan-README.md` to `.opencode/plans/<plan-name>/README.md`
2. Copy `templates/phase-N.md` for each phase
3. Fill in phases, tasks, decisions
4. Commit to repo

See `conventions.md` for full details.
